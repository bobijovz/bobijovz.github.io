# Claim Verification Checklist

Purpose: ensure the portfolio contains no fabricated professional claims and that any assertion can be verified by evidence or explicitly labeled as qualitative.

For each claim in a case study or profile section, require one of these evidence kinds:
- Link to a public artifact (repository, article, PR, demo video)
- A measurable metric (e.g., "reduced load time from 3.6s to 1.8s") with dates and method of measurement
- A named reference (e.g., verifier or stakeholder) with contact info if public and consent is given
- A signed attestation (for sensitive claims), stored off-site

Checklist to apply in PR review:
- [ ] Every claim that asserts outcome or impact has supporting evidence or is clearly labeled as anecdotal/qualitative
- [ ] No invented employer names, awards, or certifications without citations
- [ ] Monetary or revenue claims include the scope and source of the measurement
- [ ] If unsure, mark the claim for discussion and require the author to add evidence or reword

If a claim cannot be verified, prefer conservative phrasing ("reported", "team achieved", "we observed") or remove the claim.
