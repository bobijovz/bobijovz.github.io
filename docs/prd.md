# PRD: JJ Granados Technical Portfolio

## Vision
Build a fast, credible and technically sophisticated portfolio for a Senior Software Engineer specializing in mobile and cross-platform development.

## User Needs

### Recruiter
- Identify seniority and specialization quickly.
- Verify relevant experience.
- Find résumé and contact information.

### Engineering Manager
- Evaluate technical depth.
- Understand problem-solving ability.
- Inspect architecture, migration and modernization experience.

### Client
- Understand difficult problems the engineer can help solve.
- See evidence of mobile modernization and cross-platform work.
- Find an easy contact path.

## Functional Requirements

### FR-01 Professional Positioning
Communicate Senior Software Engineer, Mobile & Cross-Platform, and the statement "Mobile engineer. Software builder. Problem solver."

### FR-02 Selected Work
Present GCash, Xamarin to .NET MAUI, Damstra Learn and Tara Tsek.

### FR-03 Case Studies
Each case study contains overview, role, technology, problem, context, constraints, approach, technical decisions, implementation, validation, result and lessons learned.

### FR-04 Engineering Approach
Show Understand, Investigate, Plan, Build, Validate, Improve.

### FR-05 Career Story
Show progression from approximately 2014 Systems Engineer through Android and cross-platform engineering to current Senior Software Engineering.

### FR-06 Independent Projects
Present archived and current/planned projects separately.

### FR-07 Toolbox
Group technologies by category; do not use proficiency percentages.

### FR-08 Experience
Provide a concise professional timeline.

### FR-09 AI-Assisted Engineering
Show practical AI use for code review, debugging, tests, documentation, research, refactoring and prototyping.

### FR-10 Contact
Provide Email, LinkedIn, GitHub and Résumé.

### FR-11 Responsive
Support desktop, tablet and mobile.

### FR-12 Accessibility
Semantic HTML, keyboard navigation, focus states, contrast, reduced motion and accessible controls.

### FR-13 SEO
Metadata, Open Graph, sitemap, robots and structured data where appropriate.

### FR-14 Content Extensibility
A new case study should be addable without changing application logic.

## Non-Functional Requirements
- Static-first performance
- High maintainability
- Minimal runtime dependencies
- No unnecessary backend
- WCAG 2.2 AA practices where practical
- Strong Core Web Vitals

## V1 Acceptance
Homepage and all four case studies are responsive, accessible, SEO-ready and free of fabricated professional claims.
